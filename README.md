Para conectar Google Sheets:
1. Publicar solo la pestana WEB_DATA como CSV.
2. Copiar el enlace CSV.
3. Pegar el enlace en config.js dentro de sheetCsvUrl.
4. Subir/actualizar los archivos en GitHub.
